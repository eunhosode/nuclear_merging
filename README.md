# Nuclear Merging

양성자와 중성자를 모아 원자를 성장시키고, 광자를 피해 살아남는 입자 회피 게임입니다.

**[브라우저에서 플레이하기](https://eunhosode.github.io/nuclear_merging/)**

## 게임 방법

수소 원자핵으로 시작해 떨어지는 입자를 흡수합니다. 모은 입자에 따라 원소와 동위원소가 달라집니다.

| 색상 | 입자 | 충돌 시 효과 |
| :--- | :--- | :--- |
| 빨간색 | 양성자 | 원자번호가 1 증가하며 다음 원소로 바뀝니다. |
| 파란색 | 중성자 | 중성자 수가 1 증가하며 같은 원소의 다른 동위원소가 됩니다. |
| 초록색 | 광자 | 즉시 핵이 붕괴하며 게임이 끝납니다. |

- 양성자나 중성자를 흡수할 때마다 만들어진 동위원소의 붕괴 확률에 따라 생존 여부를 판정합니다.
- 원소 기호는 **수소 H(1번)부터 오가네손 Og(118번)**까지 지원합니다.
- 동위원소는 `He-4`, `U-238`처럼 **원소 기호-질량수**로 표시합니다.
- 질량수는 양성자 수와 중성자 수의 합입니다.

## 게임 모드

총 **12개 모드**를 제공합니다. 입자의 속도와 생성 비율, 특수 효과가 모드마다 다릅니다.

| 모드 | 일반 입자 속도 | 광자 속도 | 생성 비율 | 특징 |
| :--- | ---: | ---: | :---: | :--- |
| Easy | 3 | - | 1:2:0 | 광자를 생성하지 않는 모드 |
| Normal | 3 | 6 | 3:6:1 | 기본 모드 |
| Hard | 3 | 9 | 3:6:1 | Normal보다 빠른 광자 |
| Speedy | 6 | 12 | 6:12:1 | 일반 입자와 광자 모두 빠르게 이동 |
| Is it snail? | 1 | 18 | 3:6:1 | 느린 일반 입자와 빠른 광자 |
| Choking | 3 | 1 | 1:2:3 | 느린 광자가 화면에 오래 머무름 |
| Miserable | 3 | 9 | 1:2:3 | 높은 광자 생성 비중 |
| Schrödinger's particle | 3 | 12 | 1:1:0 | 양성자와 중성자가 각각 75% 확률로 광자로 전환 |
| Midgley's Gas | 3 | 18 | 1:2:3 | 높은 광자 생성 비중과 75% 광자 전환 확률 |
| Permian | 18 | 18 | 1:1:1 | 매우 빠른 입자와 90% 광자 전환 확률 |
| Fog | 3 | 6 | 3:6:1 | 화면 중간의 안개가 입자를 가림 |
| Paralysis | 3 | 6 | 3:6:1 | 10초마다 50% 확률로 3초간 이동 불가 |

**표 읽는 법**

- 일반 입자는 양성자와 중성자를 뜻하며, 속도는 **60 FPS 기준 프레임당 이동 거리(px)**입니다.
- 생성 비율의 순서는 **양성자 : 중성자 : 광자**이며, 생성할 입자 종류를 선택하는 가중치입니다.
- 광자는 한 번 선택될 때 원자번호에 따라 **3~6개씩** 생성되므로 실제 입자 수의 비율은 표와 다를 수 있습니다.
- 광자 전환 확률은 생성된 양성자와 중성자 각각에 적용되며, 원자핵 자체의 붕괴 확률과는 별개입니다.

## 설치 및 실행

**웹 버전**은 별도 설치 없이 [플레이 페이지](https://eunhosode.github.io/nuclear_merging/)에서 실행할 수 있습니다. 내려받은 `nuclear_merging.html`을 브라우저에서 직접 열어도 됩니다.

**Python 버전**은 Python과 Pygame이 필요합니다. 게임 파일이 있는 폴더에서 다음 명령어를 실행하세요.

```bash
python -m pip install pygame
python nuclear_merging.py
```
